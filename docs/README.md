# Performance Documentation

This folder contains performance-related documentation and test results.

## Files

- `PERFORMANCE.md` - Complete performance optimization guide
- `LIGHTHOUSE.md` - Quick Lighthouse testing guide
- `lighthouse-report.html` - Latest Lighthouse test results (gitignored)
- `lighthouse-score.png` - Screenshot of scores (add to README)

## How to Add Lighthouse Screenshot

1. Run Lighthouse test (see LIGHTHOUSE.md)
2. Take screenshot of the scores
3. Save as `lighthouse-score.png` in this folder
4. Commit to git
5. Reference in README:

```markdown
## 📊 Performance

![Lighthouse Score](docs/lighthouse-score.png)

Our portfolio achieves excellent performance scores:

- ⚡ Performance: 95+
- ♿ Accessibility: 95+
- ✅ Best Practices: 100
- 🔍 SEO: 100
```
